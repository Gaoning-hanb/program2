## 第一章 极限与连续

### 1.1 极限的定义

定义：设函数 f(x) 在点 x0 的某去心邻域内有定义，如果当 x 无限趋近于 x0 时，f(x) 无限趋近于常数 A，则称 A 为 f(x) 在 x→x0 时的极限，记为 lim_{x→x0} f(x) = A。

性质：极限若存在则唯一；局部有界性；局部保号性。

### 1.2 极限的运算法则

设 lim f(x) = A，lim g(x) = B，则：
- 加减：lim (f ± g) = A ± B
- 乘法：lim (f · g) = A · B
- 除法：当 B ≠ 0 时，lim (f / g) = A / B

### 1.3 两个重要极限

- 第一个重要极限：lim_{x→0} (sin x)/x = 1
- 第二个重要极限：lim_{x→∞} (1 + 1/x)^x = e，或 lim_{x→0} (1+x)^(1/x) = e

典型例题：求 lim_{x→0} (1-cos x)/x^2。
解法：利用 1-cos x = 2 sin^2(x/2)，并反复用第一个重要极限，得
lim_{x→0} (1-cos x)/x^2 = lim 2 sin^2(x/2)/x^2 = (1/2) · lim [sin(x/2)/(x/2)]^2 = 1/2。

### 1.4 洛必达法则

适用条件：当 x→x0（或 x→∞）时，若 f(x) 与 g(x) 同时趋于 0（0/0 型），
或同时趋于无穷大（∞/∞ 型），且 f 与 g 在去心邻域内可导、g'(x) ≠ 0，
且 lim f'(x)/g'(x) 存在（或为无穷大），则：
lim f(x)/g(x) = lim f'(x)/g'(x)。

注意：洛必达法则只能用于 0/0 或 ∞/∞ 型，其他形如 0·∞、∞-∞、1^∞ 等要先变形；
用一次后若仍为未定型可继续用；若求导后极限振荡不存在则法则失效，
此时不能断言原极限不存在，只能换方法。

易错点：分子分母各自求导，不是对整个分式求导；用之前先判断型别。

### 1.5 等价无穷小替换

当 x→0 时，常用的等价无穷小：sin x ~ x，tan x ~ x，arcsin x ~ x，
(1+x)^α - 1 ~ αx，e^x - 1 ~ x，ln(1+x) ~ x，1 - cos x ~ x^2/2。

用法：在乘除中可整体替换为等价无穷小；在加减中不能随意替换，需谨慎。

典型例题：求 lim_{x→0} (e^x - 1 - x)/(sin x)^2。
解法：分子展开 e^x - 1 ~ x，但加减不能直接替换；用 e^x = 1 + x + x^2/2 + o(x^2)，
e^x - 1 - x = x^2/2 + o(x^2)；分母 sin x ~ x，故 (sin x)^2 ~ x^2。
原式 = (x^2/2)/x^2 = 1/2。
